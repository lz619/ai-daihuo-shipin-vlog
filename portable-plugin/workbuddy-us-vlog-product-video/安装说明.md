# WorkBuddy 安装说明

本包仅用于 WorkBuddy。它不含 API 密钥、项目生成图片或视频。

1. 将整个文件夹压缩为 ZIP，或在 WorkBuddy 的“专家·技能·连接器 → 技能”中选择创建/导入技能。
2. 上传本包并完成 WorkBuddy 的安全扫描。
3. 在测试项目中确认 Skill 能读取工作目录、执行 PowerShell 脚本，并访问不鸣 AI API。
4. 在公司电脑本地重新配置 `BUMING_API_KEY` 或 `.secrets\buming-api-key.txt`；不要从个人电脑复制密钥。
5. 先使用一个测试 SKU 跑完整流程，再启用批量生成。

本包的 `SKILL.md` 已包含 WorkBuddy 所需的展示名称、中英文描述、分类、版本和作者字段；其 `references` 与 `scripts` 和 Codex 包共享相同工作流。
