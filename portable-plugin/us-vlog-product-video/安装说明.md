# 公司电脑安装说明

此压缩包不包含任何 API 密钥、个人聊天记录、项目生成图片或视频。

## Codex / ChatGPT desktop

1. 将整个 `us-vlog-product-video` 插件文件夹复制到公司电脑的固定目录，例如 `D:\AI-Plugins\us-vlog-product-video`。
2. 在 Codex 或 ChatGPT desktop 的本地插件/技能安装入口中选择该插件文件夹，或由管理员将其加入公司私有 marketplace。
3. 重启桌面应用，在新对话中确认“美国 Vlog 产品视频批量制作”可用。
4. 在公司电脑重新配置不鸣 AI 密钥；不要从个人电脑复制 `.secrets` 文件。
5. 安装 FFmpeg，并确认 Agent 有权运行此插件内的 PowerShell 脚本。

## WorkBuddy

请使用同级目录的 `workbuddy-us-vlog-product-video` 包，而不是本包。WorkBuddy 对 `SKILL.md` 的元数据字段要求与 Codex 不同，因此两包共享脚本和工作流，但分别保留各自兼容的前置字段。

## 重要安全规则

- API 密钥只在公司电脑本地重新配置，绝不打进压缩包、Git 仓库或共享盘。
- 每批新的 Omni 1.1 付费生成前，仍需明确授权。
- 首批上线时先用一个测试 SKU 验证完整流程，再开放多 SKU 并发。
