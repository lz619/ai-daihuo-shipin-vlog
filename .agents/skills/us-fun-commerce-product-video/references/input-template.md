# Excel 输入表填写说明

固定在当前实际调用 Skill 的 `assets/product-input-template.xlsx` 的“产品输入”工作表录入。本仓库常用文件的绝对路径是 `E:\我的ai带货视频skills\.agents\skills\us-fun-commerce-product-video\assets\product-input-template.xlsx`。目录名是 `.agents\skills`。仓库根目录同名 Skill、旧版 Skill、打包/验证目录中的同名 Excel 不作为默认输入。

每一行是一条独立 SKU；同一 SKU 需要多条视频时，在“视频数量”填写数量。不要覆盖第 1 行标题。本机安装保留了用户已有填写内容；新 SKU 另起一行，不自动补造商品事实。填写后按 Ctrl+S 保存。以后说“用这个 skill 的 assets 表格做 SKU 002”即可，无需每次重新提供路径；用户明确提供其他工作簿路径时，只读取指定文件。

| 列名 | 必填 | 填写方式 |
| --- | --- | --- |
| SKU | 是 | 唯一 SKU 标识，只用英文字母、数字、下划线或连字符。 |
| 产品名称 | 是 | 商品在素材或商品资料中的名称。 |
| 产品图片 | 是 | 填可访问的真实商品图片本地绝对路径；多张图片分行填写。 |
| 产品信息 | 是 | 用中文填写商品是什么、已确认功能、支持解决的痛点、目标人群、生活场景和正确使用方法。仅写资料确认内容；未知项标明“待确认”。 |
| 卖点 | 是 | 按 1、2、3……列出资料确认的卖点。制作每条视频时只选一个核心卖点。 |
| 视频数量 | 是 | 正整数，表示该 SKU 计划制作的视频条数。 |
| 队列状态 | 否 | 默认“待规划”。“跳过”表示本轮忽略该行。 |
| 视频模型 | 否 | 可填所选模型；不确定时保留模板默认值。 |
| 分辨率 | 否 | 可按制作需要选 720P、1080P 或 4K。 |
| BGM 文件路径（可选） | 否 | 需要指定背景音乐时填写本地路径；不填则不假定使用特定音乐。 |
| 项目备注（可选） | 否 | 填本 SKU 的创意限制、偏好或补充说明，不要用它代替商品事实来源。 |

保存后，在对话中提供工作簿路径及要制作的 SKU，例如：

```text
请使用 $us-fun-commerce-product-video 自动制作这个 Excel：<你的工作簿路径>
SKU：<要制作的 SKU>
```

填好的 Excel 是第一处需要你准备的内容。自动流程会读取商品信息并继续策划、生成首帧；它会另外询问不鸣 AI 模型/分辨率，并在五张首帧生成后暂停给你验收。空白模板只是录入结构，不是商品事实或商品图片。
