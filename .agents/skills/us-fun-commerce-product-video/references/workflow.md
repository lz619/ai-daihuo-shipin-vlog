# 工作流与真实性规范

## 1. 观众心理和五镜头销售结构

默认剪辑时长 15–20 秒，以下分配是本 Skill 的创作建议，不是平台硬性规则。可按英文台词语速微调，但必须完整保留理解商品所需的镜头。

| 镜头 | 建议时间 | 观众此刻的问题 | 镜头任务 |
| --- | --- | --- | --- |
| S01 强钩子 | 0–2.5 秒 | “刚才发生了什么？接下来会怎样？” | 先用可一眼读懂的悬念、视觉冲击或新奇反差打断滑动；普通点出痛点不算完成钩子 |
| S02 揭示与产品出现 | 2.5–5 秒 | “原来和这个商品有关？它能做什么？” | 回答/延展 S01 留下的问题，以明确因果把商品带入画面；观众能辨认产品及关联 |
| S03 正确使用 | 5–9 秒 | “它怎么用？” | 清晰展示一项已证实的关键操作、接触点或步骤 |
| S04 可见证据和价值 | 9–14 秒 | “我能看到什么变化或信息？” | 用真实演示呈现商品资料支持的变化、读数、输出、完成状态或其他可观察证据；不虚构效果 |
| S05 兑现与行动 | 14–18/20 秒 | “前面的问题解决了吗？它适合谁？” | 回扣开场并交代结果；联系具体受众或使用情境，给自然的分享/查看/选购理由；只有已知优惠才能提优惠 |

遵循“钩子拿停留，效果拿信任，结果和人群共鸣带来分享与购买”。销售信息不可被趣味挤掉：S02 结束时观众应知道商品是什么、为什么出现在这里；S03–S04 应能看懂真实用法和可验证效果；S05 兑现开场并给出受众相关的下一步。若 5 秒后仍不知道商品与开场的关系，重写接桥；若商品效果无法演示，不可用夸大承诺替代证据，应展示真实操作、输出或可观察状态，并说明资料边界。

## 2. 强钩子设计与筛选

不得把“指出痛点”本身当成强钩子。先按 [高停留钩子与产品证明设计](hook-and-proof.md) 生成至少三个结构不同的 S01 候选，分别考虑悬念/神秘感、视觉冲击、新奇/反差；胜出方案须让三项中的至少两项从首帧或第一个动作就能看出来。钩子可以先不露商品，也可以让产品以谜面/反差方式出现，取决于哪个更有停留力。

每个候选开场都先写出：

- 0–1 秒观众看到什么，是否一眼读得懂；
- 观众会产生什么具体问题/预期；
- 悬念、视觉冲击、新奇/反差中哪些要素实际出现在画面里；
- 它怎样在 S02（通常 2.5–5 秒内）引出商品和已证实需求；
- S03–S04 将用什么真实视觉演示兑现期待；
- 哪个具体受众会觉得“这说的是我/我要发给某人”；
- 是否适合当前生成方式：主体清楚、动作简单、连续性可控。

候选按 0–2 分快速评估：首帧可读性、好奇缺口、视觉辨识度、与商品的因果连接、生成/拍摄可实现性、事实与安全边界。总分只用于候选之间比较；首帧可读性、产品连接、可实现性或事实边界任一项为 0，就淘汰。避免只是换说法的普通痛点开场；如果三条候选都平淡，先换画面机制，不要急着编更夸张的台词。

以下任一项成立就淘汰：只有一句“你是否也有……”而没有视觉动作；为猎奇而猎奇、S02 不能接回商品；暗示未经证实的产品能力/效果、危险或故障；结果不能由资料和演示支持；依赖多人精密互动、复杂物理或产品结构变形才能成立。创意可以大胆，画面执行仍需单镜头一个主要动作、可生成可检查。

商品最迟 S02 清晰出现，建议在 2.5–5 秒内完成“发生了什么 → 商品为什么出现”；这不是把钩子拖到 5 秒，而是钩子之后立即接桥。若商品本身最能形成视觉钩子，可从 S01 露品。不得让无关段子占满前半条视频。

## 3. 美区日常 Vlog 质感与减少 AI 感

真实感来自具体生活和克制拍摄，不来自刻意加噪点或套“美国滤镜”。应按 SKU 的真实使用场景写一位具体但不刻板的美国日常使用者、一个可生成的普通空间和一种手机拍摄方式。只用事实卡或真实图支持的商品与操作；背景生活物件只做陪衬，不能暗示配件随货附送或参与未证实功能。

方向卡及每条提示词遵循：

- 人物像在给朋友分享刚发生的小事：自然停顿、目光短暂移开、轻微犹豫或笑意；不过度直视镜头，不用广告主持腔、夸张惊讶脸、完美口型和机械微笑。
- 场景是可解释的普通生活空间，保留少量真实使用痕迹和合理物件；空间整洁但不似样板房。避免堆砌星条旗、地图、夸张郊区住宅、豪车、品牌标志来“证明美国”。
- 使用自然窗光或普通室内实用光，肤色和白平衡自然。保留轻微手机手持漂移或固定手机的平实视角；不使用电影级运镜、棚拍轮廓光、过浅景深、厚滤镜、过度磨皮、无缘由慢动作或炫技转场。
- 人物、衣着、空间、商品结构/颜色/方向、产品状态与主要道具跨镜头连续。手机视角和人手关系需物理可行；需双手操作时改用固定机位。
- 避免让商品悬浮、瞬移、变形、无手接触自动操作；避免手指遮住关键操作点或显示区域。镜头切换应由注意力/动作自然推动。
- 音画与口播像同一位创作者在一个真实场景里完成；只写必要台词，语气自然、简短、不做虚假亲测背书。

每个镜头通过“像真实手机视频吗”验收：光线是否平实；人物是否在做具体事情而非摆拍；商品是否与手和环境接触合理；运动是否简单连续；背景是否服务于生活情境；是否出现常见 AI 缺陷（手部畸形、物品漂浮、纹理闪烁、脸/商品漂移、瞬间变焦、动作中途跳帧）。出现明显缺陷就返工，不以描述“不要 AI 感”代替具体约束。

## 4. 操作、证据与商品真实

- 仅以 Excel 和真实商品图锁定 SKU 的结构、材质外观、尺寸比例、颜色、标识、方向、按钮、接口、配件、操作步骤、适用对象与效果。
- 商品图可以锁定身份/结构，但白底图不能作为最终生活场景或白底广告构图的依据。
- 对比、数字、提示灯、屏幕文字/数值、前后状态必须来自资料；不得凭空填入更理想的读数或结果。若图中数字不可辨，不生成可读数字并标为待确认。
- 每条只选一个核心卖点和一个主要证明路径。口播、画面和商品页不得互相矛盾。
- 美国英语对白须适合规定的保留时长；不暗示编造评论、长期体验、医学/安全保证、稀缺、折扣或“最好”。

## 5. 图生视频可实现性

一个镜头一个主要人物/商品动作，起始状态与结束状态可由单段运动连起来。首帧放在动作发生之前。优先小幅手部操作、转头、拿起、放下、看向屏幕、自然表情反应、简单固定机位；需要复杂安装或精确数值时应先用多张静态首帧/后期剪辑拆解，而非让模型一次完成。

避免多对象同时运动、连续递接、快速跑跳、复杂身体遮挡、镜中反射、多步骤精细装配、边开车边自拍/操作、商品结构变换、快速手指输入、细小屏幕内容动态生成。提示词只描述首帧后的变化，不重复静态场景细节。生产提示词默认排除字幕、错误商标、水印、额外人物/手、背景音乐和第二个说话人；对白按用户选定的制作环节提供。

## 6. 多视频与多 SKU 的创意差异

批量规划前建立一张中文创意路由表，为每条视频标记：趣味钩子类型、人物状态/关系、具体空间、商品露出方式、证明方式、核心卖点、结尾购买理由。每个 SKU 的事实和适用场景只从该行 Excel 与该 SKU 的真实图片确认，不能把相似商品的操作或效果迁移过来。

同 SKU 的不同视频至少在以下六项中有三项实质不同：钩子类型、人物状态、生活空间、产品出现动作、支持的演示/证据方式、收尾购买理由。不同 SKU 应先按真实使用场景和卖点选不同钩子，不应为了凑齐类型而给商品套不匹配段子。改台词但画面和证明不变，不算创意差异。

建议先试“谜面揭晓、结果先露一角、尺度反差、身份/场景错位、动作反常但安全、前后强对比、评论回应”等创作类别；它们是内部灵感标签，不是 TikTok 官方分类。优先保留可复用的停留机制，重做具体人物、环境、动作和事实证据。生活真实感约束拍摄质感，不限制创意只能做轻微日常动作。

## 7. 五镜头脚本与素材字段

以下字段填写到 [统一制作计划](structured-plan.md)，再由程序生成供人阅读的 Markdown。模型核对创意和事实，程序检查结构、镜头顺序、来源引用、时长与任务一致性；格式校验不能代替语义和视觉审核。

每条脚本含 S01–S05，每镜头必须写：镜头职责；画面内容；唯一主要动作；起始状态；结束状态；必须可见的商品部分；人物/场景连续性；机位和可行拍摄方式；一项自然 Vlog 细节；精确美式英语台词；剪辑保留秒数。标出预计商品首次出现时间与总时长。

P/R 计划只列必要资料：P 是真实商品图及其锁定结构；R 是确需跨镜头保持一致的人物/空间锚点。记录真实路径；缺图写阻塞，不编造路径。每张静态首帧写实际需上传的参考图、各自锁定内容、中文完整提示词、验收清单。只有图像实际保存并审核后才登记为 approved。

### 空间连接关系的 PoseMaster 默认规则

仅当镜头提示词涉及商品的安装、插入、夹持、磁吸、卡扣、套入、连接、支撑、旋转等空间连接/受力关系时启用本规则；其他镜头照常选择参考图。

- 从真实商品资料中优先选一张 30°–60° 斜侧参考图，必须同时清楚看到商品主体和对应连接结构，并在 P/R 计划与上传清单中标为 `PoseMaster`。
- 生成该镜头静态首帧时，将 PoseMaster 作为商品三维姿态的最高优先级依据：它锁定主体朝向、连接轴线、深度/插入方向、接触面和相对位置。正面图可辅助锁定屏幕、按键、标识等外观细节，但不得覆盖或改写 PoseMaster 的姿态与连接关系。商品身份、功能及可见细节仍须符合 Excel 和真实商品证据。
- 在提示词中明确写出 PoseMaster 的优先级，并说明其他商品图各自仅锁定哪些细节；不要让多个视角互相争夺空间姿态权威。
- 验收时检查主体与连接结构的轴线、角度、接触/咬合位置、插入深度及相对比例是否与 PoseMaster 一致；排除悬浮、穿模、错位或连接件缺失。
- 若现有真实商品图没有合格的 30°–60° 斜侧图，或无法同时辨认主体和连接结构，标记依赖此关系的镜头为阻塞并请求补充真实斜侧图；不得用正面图猜测三维坐标，也不得虚构/重建连接结构来冒充参考图。

每个触发规则的首帧清单需包含专门的 PoseMaster 验收项。无空间连接关系的镜头不强制使用 PoseMaster。

## 8. 自动执行与人工确认点

按 [自动执行流程与人工确认点](automation.md) 执行。策划时先完成至少三个差异化开场候选和钩子筛选，再将胜出的视觉钩子落实到首帧，检查 S02 产品接桥及 S03–S04 视觉证明。用户需要手动准备/回复的项目仅为：填好并提供 Excel；选择不鸣 AI 模型和分辨率；在五张首帧展示后验收并决定继续或返工。其他环节（Excel 校验、策划、首帧生成/保存/检查、提示词、已批准后的 API 提交、轮询下载、按剪辑时长修剪、拼接和结果检查）由 Codex 自动完成。

必须在静态首帧阶段暂停：展示五张真实生成的图片及路径、询问“需要修改哪张，还是确认继续”，等待明确答复。不得预先发视频生成请求，不得仅凭自己审核把状态设为 `approved`。用户要求修改时仅返工相应图片并再次展示；用户批准继续后才能标记 `approved` 并执行后续 API 任务。

## 9. 每条视频完成前检查

- [ ] S01 不是只讲痛点；悬念、视觉冲击、新奇/反差至少两项能从画面看出来，且首秒可读。
- [ ] 至少比较三个不同开场候选；胜出方案通过好奇、可读性、产品连接、可实现性与真实性筛选。
- [ ] S02 在钩子后几秒内揭示商品并解释关联；到 S02 结束观众能说出商品是什么、为何出现。
- [ ] S03 展示已证实的正确用法；S04 用真实、可演示的视觉证据展示结果/输出/可观察状态，不只口头说有效。
- [ ] S05 兑现开场留下的预期，联系明确受众，给出可信的分享或购买理由。
- [ ] 若钩子制造的期待无法由真实产品效果兑现，已重写钩子，而非保留误导性噱头。
- [ ] 所有商品事实都能追溯到对应 Excel 字段或图片。
- [ ] 五镜头各一个可生成、可拍摄的动作，剪辑时长合规。
- [ ] 美区生活空间自然具体，不靠刻板符号；人物不演成广告演员；画面不过度精修。
- [ ] 商品、手、道具、人物、光线和机位跨镜头连续；图像和视频通过事实与 AI 缺陷检查。
